Objetivo

Desenvolver uma aplicação capaz de armazenar e manipular vetores de números reais utilizando arrays como estrutura de dados. A aplicação deverá implementar operações matemáticas sobre os vetores e calcular a similaridade de cosseno entre eles.

O exercício tem como objetivo avaliar a capacidade do aluno de utilizar arrays para armazenamento de dados, realizar acesso e processamento de seus elementos por meio de índices e implementar operações sobre a estrutura sem recorrer a bibliotecas que forneçam diretamente essas funcionalidades.

O array deverá ser utilizado como estrutura concreta de armazenamento, considerando suas características de acesso direto por índice e armazenamento de elementos do mesmo tipo.s

 

Descrição do problema

Considere que uma aplicação de análise de dados representa cada objeto por meio de um vetor numérico de dimensão n. Cada posição do vetor representa uma determinada característica do objeto.

Por exemplo, um objeto pode ser representado pelo vetor:

[0.80, 0.20, 0.50, 0.90, 0.30]

Dois objetos podem ser comparados verificando-se a proximidade entre seus respectivos vetores.

Desenvolva um programa que permita criar, armazenar e manipular vetores de números reais (float), além de calcular a similaridade entre dois vetores utilizando a similaridade de cosseno.

A implementação deverá ser realizada em C, Python ou Java. Nenhuma biblioteca externa pode ser utilizada para a implementação das estruturas de dados ou operações que utilizem a estrutura de dados.

 

Operações da Estrutura de Dados:

As operações do array, que representam os métodos, devem se chamar:

·       inicializar_array

·       inserir

·       imprimir

·       buscar

·       remover

 

Funcionalidades do sistema com a estrutura de dados:

O programa deverá permitir que o usuário:

informe o tamanho;
crie dois ou mais vetores;
informe os valores reais de cada vetor;
exiba os vetores armazenados;
multiplique um vetor por um valor escalar;
calcule a soma de dois vetores;
calcule o produto escalar entre dois vetores;
calcule a norma de um vetor;
calcule a similaridade de cosseno entre dois vetores;
determine, entre um conjunto de vetores, qual possui maior similaridade com um vetor de consulta.
